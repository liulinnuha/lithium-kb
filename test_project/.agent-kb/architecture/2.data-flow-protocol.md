# Data Flow Protocol & Telemetry

## Overview
All inter-agent messages are serialized as binary frames over WebSocket connections.

### Telemetry Channels
- **`/telemetry/heartbeat`**: Agent health status every 500ms.
- **`/telemetry/memory-hit`**: Real-time cache hit notifications for active reasoning contexts.
- **`/telemetry/execution-trace`**: Step-by-step tool invocation DAG.
