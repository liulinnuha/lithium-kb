# Debug 1: SSE Buffer Overflow under High Concurrency

- **Date:** 2026-08-10
- **Severity:** High
- **Status:** Resolved

## Root Cause
When more than 200 clients connected simultaneously, the unbuffered SSE write queue consumed excessive heap memory, triggering Garbage Collection pauses.

## Fix
Implemented backpressure handling with highWaterMark limits in the stream handler.
