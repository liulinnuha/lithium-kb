# Feature 2: Time-Travel Execution Debugger

- **Version:** v1.6.0 Target
- **Description:** Allows developers and agents to step backwards through agent reasoning steps and branch alternate solution attempts.

## Interface
- `quantum.rewind(stepId: string)`: Reverts agent state to designated checkpoint.
- `quantum.branch(newGoal: string)`: Forks a new speculative execution DAG.
